# Clases de Español · Cole

Material interactivo de clases de español para Cole, estudiante de nivel A0 (principiante absoluto), enfocado en cultura, viajes y aficiones.

## Perfil del estudiante
- Nivel: A0 (evaluado por Preply)
- Lengua materna: inglés
- Objetivo: hablar de cultura, viajes y aficiones
- Focos de aprendizaje: fluidez, confianza, precisión, pronunciación, comprensión oral
- Aficiones: TV/películas, tecnología, mascotas, viajes, deportes, comida, gimnasia, moda, cultura, aventuras al aire libre
- Ritmo: 18 clases al mes

## Contenido
- `clase1_cole_bienvenida.html` — Clase 1: bienvenida, sonidos básicos, saludos y "yo soy..." para presentarse.
- `plan_clases_cole.html` — Planificación interactiva de las 18 clases del mes 1, organizada por semanas.

## Cómo usar
Abre cualquier archivo `.html` directamente en el navegador. Cada clase incluye vocabulario, práctica guiada y una mini evaluación interactiva.
